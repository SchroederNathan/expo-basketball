# A separate icon background

The app icon now uses a deep navy background with an orange basketball. This distinguishes the new app in the launcher. The change affects only this repository's `assets/icon.png`.

The built-in imagegen tool edited the asset. Expo prebuild generated an opaque 1024 by 1024 iOS icon from it.

The edit prompt was:

> Edit the provided app icon. Change only the background color: replace the near-black warm brown background with a clean, rich deep navy blue background, base hex #142B48. A very subtle navy radial tonal variation is okay. Preserve the orange basketball outline exactly in shape, stroke thickness, location, size, and bright orange color. Preserve the circular outline and all internal curved/straight seams. Do not add text, letters, border, shadow, objects, 3D, texture, highlights on the mark, or rounded corners. This is a flat iOS/Android app icon asset, square edge-to-edge opaque background, 1024 by 1024 pixels. Basketball centered with the same generous padding as the input. The only intended change is the background hue to navy.
