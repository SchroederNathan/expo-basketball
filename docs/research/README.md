## Source conventions

Record the source URL and review date. Distinguish documented behavior, repository observations, and proposals. Label draft documentation and account-gated features. Replace preview URLs with published documentation after release, and recheck workflow examples before implementing them.

The Expo sources reviewed here are draft pages supplied for this discussion. Linking them in these notes does not mean the docs or Expo Simulators are generally available. The original research was read-only. The feedback file links later implementation runs and distinguishes completed checks from pending cloud verification.
